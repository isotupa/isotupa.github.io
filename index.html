Selected projects

Master's thesis · Wahoo Fitness · 2025–26

A grey-box virtual torque sensor for a smart bike trainer

Wahoo's CORE2 trainer estimates rider power from a factory-calibrated lookup table that has to be rebuilt whenever the hardware changes. I replaced it with a physics model plus a learned residual, added a reject option so the model abstains instead of inventing impossible torque, and tested whether the learned parameters survive a move to a second production unit.

A memetic TSP solver with a restart that actually restarts

An evolutionary algorithm for the travelling salesman problem where 2-opt local search runs on every single offspring. The population is small because the search is expensive, and when it stalls the whole population is thrown away and rebuilt from the best individual.
